About Salary Prediction Project

Salary Predictor AI is a Machine Learning based web application that predicts an employee's salary based on years of experience. The project demonstrates the complete Machine Learning workflow, from data preprocessing and model training to deployment using Flask.

🎯 Project Goal

Predict employee salary accurately using experience data and provide instant results through a user-friendly web interface.

🤖 Machine Learning Model

Linear Regression is used because salary is a continuous variable and has a direct relationship with years of experience.

📊 Data Analysis

Data preprocessing, cleaning, feature selection, visualization and model training were performed using Python libraries.

🐍 Python Libraries

NumPy, Pandas, Matplotlib, Scikit-Learn, Joblib and Flask were used throughout the project.

🌐 Web Development

Flask powers the backend while HTML and CSS create an attractive and responsive user interface.

💾 Model Deployment

The trained model is saved using Joblib and loaded dynamically within Flask for real-time predictions.
